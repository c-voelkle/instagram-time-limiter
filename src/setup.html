Set your password

Choose a password to protect this extension. You'll need it to change or turn off the daily limit and curfew.

If the extension is removed, this address gets an email. The popup shows a notice about this, so nobody is surprised. Send a test email once: the first email asks the contact to confirm (“Activate Form”) before notifications can arrive.

There's no way to recover a forgotten password. If whoever is being held to the limit shouldn't know it, have someone else type it in.
