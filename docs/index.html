Time Limiter for Instagram

A free browser extension that caps your daily time on Instagram and X, enforces a bedtime curfew, and locks the settings behind a password so the limits stick.

Install in Chrome

About one minute. No account needed.

Download extension (.zip)
  1. Unzip the download. On Windows, right-click it and choose Extract All. Keep the folder somewhere permanent, such as Documents. Deleting it removes the extension.
  2. Open chrome://extensions in the address bar.
  3. Turn on Developer mode (switch in the top-right corner).
  4. Click Load unpacked and choose the unzipped folder.
  5. A setup tab opens. Choose a password, and you're done.

The Chrome Web Store charges developers a fee, so this free version is installed manually. It runs exactly the same.

Safari

Safari extensions have to be built with Xcode on a Mac, and distributing them costs an Apple developer fee, so there's no free Safari version. Chrome, Edge, Brave, Firefox and Opera all work on a Mac.

Daily time limit

Counts only the time Instagram or X is actually on screen, from one shared budget.

Bedtime curfew

After the time you pick, Instagram and X are off until midnight: “Es ist Zeit, ein Buch zu lesen!”

Friendly reminders

A 10-second countdown when time runs out, then a cheerful “Es ist Zeit, Deutsch zu lernen!” instead of the feed.

Password lock

Changing or switching off the limits needs a password. Hand it to someone you trust.

Questions

What data does it collect?

None. Your usage time and settings stay in your browser's local extension storage and are never sent anywhere. See the privacy policy.

What does the password protect?

Changing the daily limit or curfew, or turning them off. During setup you can also lock the browser's extensions page, so the extension can't simply be switched off there without the password. Browsers still let an extension be removed from the toolbar menu, so the lock is a strong speed bump rather than an unbreakable wall.

I forgot my password

It can't be recovered, because only a secure hash is stored. Remove the extension (right-click its toolbar icon → Remove) and install it again.

Does it work in private/incognito windows?

Only if you allow it. Open the extension's details on the extensions page and turn on “Allow in Incognito” (Chrome/Edge) or “Run in Private Windows” (Firefox). Do this before locking the extensions page.

How do I update it?

Store versions (Edge, Firefox) update automatically. For a manual install, download the new zip, replace the contents of your folder, and click the reload icon on the extension's card on the extensions page.
